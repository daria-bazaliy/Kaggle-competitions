# Safe Driver Risk Prediction

Kaggle team competition (private, run as part of a university ML course)

## Overview

Binary classification task: predict the probability that a car insurance 
policyholder will file a claim, using a set of anonymized customer features. 
Of the three competitions, this one was the most relevant to my interest in 
risk analytics in fintech/insurance.

## Data

Anonymized, heavily engineered customer and vehicle features (provided by the 
competition organizers on Kaggle).

## Method

- Team-based EDA and feature engineering on anonymized/encoded features
- Classification models evaluated via F1 score
- Class imbalance was a core challenge, typical of insurance claim prediction

## Result

F1 score, ranked near the bottom of the course leaderboard on a heavily 
imbalanced dataset. The competition that motivated my interest in risk 
modeling more than the leaderboard position did.

## Tools

Python (pandas, scikit-learn)
