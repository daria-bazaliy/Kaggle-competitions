# Restaurant Closure Prediction

Kaggle competition (private, run as part of a university ML course)

## Overview

Binary classification task: predict whether a restaurant will close within its 
first two years of operation, based on characteristics known at opening.

## Data

Anonymized restaurant-level features available at the time of opening (provided 
by the competition organizers on Kaggle).

## Method

- Exploratory data analysis and feature engineering
- Logistic regression and tree-based models (Random Forest / gradient boosting)
- Model selection and validation based on the competition's evaluation metric

## Result

**ROC-AUC — ranked 25th out of 128** course participants

## Tools

Python (pandas, scikit-learn, XGBoost/LightGBM)
