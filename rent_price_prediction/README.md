# Rent Price Prediction

Kaggle competition (private, run as part of a university ML course)

## Overview

Regression task: predict rental price based on property and location features, 
optimizing for Mean Absolute Error (MAE).

## Data

Anonymized property listing features (provided by the competition organizers 
on Kaggle).

## Method

- Feature engineering and handling of categorical/numerical variables
- Regression models (linear regression and tree-based ensembles), compared 
  by cross-validated MAE
- Final model selection based on leaderboard performance

## Result

**MAE — ranked 18th out of 129** course participants

## Tools

Python (pandas, scikit-learn, XGBoost/LightGBM)
